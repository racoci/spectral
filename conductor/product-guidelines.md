# Product Guidelines

## Mathematical Rigor and Reproducibility
- All mathematical formulations must be grounded in continuous and discrete signal theory (Hardy spaces, differential jets, RKHS, Takenaka-Malmquist bases, etc.).
- Implementations must be fully reproducible with deterministic seeds where random generation is used.
- Benchmarks must output standardized metrics: SI-SDR (dB), computation time (seconds / ms), and parameter counts / description length proxies.
