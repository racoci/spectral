# Product Definition - Audio2Image / MDL Structural Codec

## Vision
Audio2Image is an advanced audio representation and compression framework based on Minimum Description Length (MDL) principles, Holomorphic Geometry, Continuous Differential Jets, and Structural Synthesis. It unifies time-frequency analysis (Hardy spaces, Cauchy wavelets, Bargmann-Fock spaces) with reversible parametric modeling (TreeNN, SynthNN) to produce interpretable, ultra-compact audio representations.

## Target Audience
- Researchers and DSP engineers in audio compression, music information retrieval, and neural audio modeling.
- Developers needing reversible, bit-exact or high-fidelity parametric audio codecs.

## Core Features
1. **Mathematical Curriculum:** Rigorous synthetic signal laboratory (Phase 1) and mathematical competitor benchmarking (Phase 2).
2. **Structural Representations:** Comprehensive comparison of continuous, discrete, adaptive, and neural representations (M1 through M12).
3. **Information-Theoretic Codec:** Minimization of total description length $L(M) + L(R)$ balancing parametric complexity against residual entropy.
4. **Lean 4 Synth IDE & Dual Representation:** An interactive environment pairing human-readable, plain-text Lean 4 code with inline Svelte 5 widgets (FM routing matrix, draggable envelope stages, knobs), featuring surgical bidirectional synchronization and DX7 `.syx` preset ingestion.
5. **Scalar Field 2D & Taylor Jets IDE:** Interactive 2D scalar field exploration and editing environment pairing plain-text Lean 4 code with a hybrid WebGL 2 (isoline and continuous field at 60 FPS) and 2D vector polar handles overlay (Taylor jets orders 0 to 8, $q_n(\theta)$). Includes continuous spatial brushes with inertial smoothing, kinematic chain rule validation along trajectories, and dual audio synthesis (Wavetable orbit scan & DDSP spectral surface).
6. **Unified UI Design System & Multi-Tool Ergonomics:** Centralized atomic design architecture (`src/lib/ui/`) featuring custom rotary knobs, segmented pill tabs, collapsible panel cards, resilient splitters, and anti-occlusion smart tooltips. Includes a global topbar navigation system with Alt+1..6 keyboard routing, live Web Audio playback indicators, and dynamic `ResizeObserver` adaptive buffers preserving exact aspect ratios and high-DPI clarity across laptop, desktop, and ultrawide displays.
7. **MDL Phase 7 RDO & DRED Codec:** High-performance rate-distortion optimization engine and 14-bit rANS entropy codec inspired by Opus 1.5 DRED. Implements soft dead-zone quantization, automatic overcomplete latent dimension pruning, and dual-mode bitstream packaging: ultra-low bitrate lossy DRED (<16 kbps with 34x compression) and 100% bit-exact lossless integer residual reconstruction ($x_{\text{int}} = \text{round}(\hat{x}_{\text{int}}) + r$).
8. **MDL Phase 7 Probabilistic Ridge Tracking & Association (E46-E50):** 4D Extended Kalman Filter (EKF) and GP-SDE state estimation ($f, \dot{f}, \ln A, \dot{A}/A$) with 95% chi-square covariance calibration. Features optimal bipartite data association via Mahalanobis distance and the Hungarian algorithm, robust trajectory preservation during partial crossings (<1% identity swap), explicit birth/death lifecycle management, and Gaussian Process spectral inpainting bridging temporary occlusions (<0.10 cents error).
9. **MDL Phase 8 Learned Ridge Codec & Surprise Encoding (E51-E59):** Data-driven trajectory compression with orthonormal learned dictionary ($\mathbf{\Phi} \in \mathbb{R}^{L \times K}$), reducing MSE by >40% over 1D DPCM. Features conditional innovation modeling, 14-bit rANS entropy coding, and Bayesian surprise gating ($\Delta G > \lambda$) suppressing >70% of redundant transmissions during stable sustained harmonics with <1.2 cents reconstruction error.
10. **Session Sharing via Compact Reconstruction Format, Offline PWA & SVG Export:** Universal session portability storing only ontological generative parameters ($<0.5$ KB per link) for client-side analytical resynthesis without transferring heavy PCM audio. Includes native Progressive Web App (PWA) offline cache with Stale-While-Revalidate WebAssembly delivery and infinite-resolution structural SVG vector export.
11. **Slang GPU Shaders & WebGPU Compute Pipeline:** Next-generation GPU acceleration compiling Slang shaders with native forward/reverse automatic differentiation (`fwd_diff`/`bwd_diff`) for higher-order Taylor jets (orders 0 to 8). Features WebGPU compute kernels for continuous brush deformations and antialiased isolines at 120 FPS with seamless WebGL 2 fallback.
12. **SynthNN & TreeNN Hierarchical Causal Graph (E60-E63):** Interpretable neural-causal sound synthesis discovering modular synthesizer topologies from audio. Starts from a fully connected coupling matrix $\mathbf{W} \in \mathbb{R}^{N \times N}$ and collapses redundant paths via MDL structural edge pruning (>75% edge reduction with >30 dB SNR). Supports smooth $\tanh$ feedback stability and live execution in the DDSP Studio.
