# Spectral Session Sharing & Offline PWA Suite

Este diretório contém a documentação da arquitetura de portabilidade e execução offline do Spectral:

- `compact_reconstruction_format.md`: Especificação do formato canônico `SpectralPackage` e codificação URL-safe.
- `url_sharing_interaction.md`: Interação do usuário ao compartilhar e restaurar sessões.
- `pwa_offline_architecture.md`: Configuração do manifesto PWA e estratégia Stale-While-Revalidate do Service Worker.
- `SESSION_PORTABILITY_HANDOFF.md`: Handoff de portabilidade e salvaguardas de integridade.
